N高ポータル — 技術仕様書 v2.0.0

学内情報ポータル・生徒投稿機関誌・コミュニティプラットフォーム

HTML5 CSS3 JavaScript ES2020 TypeScript 5 Python 3.12 SQL / SQLite JSON YAML Bash

プロジェクト目的

N高等学校・S高等学校の生徒が、校内ニュース・イベント・部活動・生徒投稿機関誌を一元管理できる学内ポータルサイト。学校発行の Google Workspace アカウントでのみアクセス可能。

主要機能

  • Google OAuth 2.0 ログイン — 学校ドメイン限定（hd パラメータで制御）
  • 校内トピックス — カテゴリ別フィルタリング・地域フィルタ・全文検索・コインによるトップ固定
  • 生徒投稿 機関誌エディタ — セクションベースのリッチ記事作成（見出し/本文/画像/引用）
  • 114514ウォレット — 仮想コインによるイベント申込・グッズ購入・記事固定・SVGスパークライン
  • 右レール — キャンパス別天気・カレンダー連携予定・急上昇ワードをリアルタイム表示
  • 部活Wiki (wiki.html) — 紙芝居スライド方式のクラブ情報ページ
  • 急上昇ワード (trending.html) — 検索ログ集計・紙芝居スライド・SVGスパークライン
  • 知恵袋 (qa.html) — コインバウンティ付きQ&Aボード
  • フリマ (flea.html) — コインのみ・対面受け渡し限定の校内フリーマーケット
  • カレンダー (calendar.html) — 個人カレンダー・締切管理・index.html連携

Google OAuth 統合

auth.js — Google Identity Services JavaScript 
// 設定（必ずサーバー側でも検証すること）
var GOOGLE_CLIENT_ID = "YOUR_CLIENT_ID_HERE";
var SCHOOL_DOMAIN    = "n-high.jp";

function startGoogleLogin() {
  google.accounts.id.initialize({
    client_id: GOOGLE_CLIENT_ID,
    callback:  handleCredential,
    hd:        SCHOOL_DOMAIN     // Google 側でドメイン制限
  });
  google.accounts.id.prompt();
}

function handleCredential(response) {
  // JWT を Base64 デコードしてユーザー情報を取得
  var payload = parseJwt(response.credential);

  // クライアント側でもドメイン検証（二重チェック）
  if (!payload.email.endsWith("@" + SCHOOL_DOMAIN)) {
    toast("学校アカウントでログインしてください");
    return;
  }
  completeLogin(payload.name, payload.picture, payload.email);
}

// JWT の Base64url デコード（表示用・署名検証は行わない）
function parseJwt(token) {
  var b64 = token.split(".")[1]
    .replace(/-/g, "+").replace(/_/g, "/");
  return JSON.parse(decodeURIComponent(
    atob(b64).split("").map(function(c) {
      return "%" + ("00" + c.charCodeAt(0).toString(16)).slice(-2);
    }).join("")
  ));
}

app.py — Flask API サーバー Python 3.12 
from flask import Flask, request, jsonify, abort
from google.oauth2 import id_token
from google.auth.transport import requests as google_requests
import sqlite3, os

app = Flask(__name__)

GOOGLE_CLIENT_ID = os.environ["GOOGLE_CLIENT_ID"]
SCHOOL_DOMAIN    = os.environ.get("SCHOOL_DOMAIN", "n-high.jp")

def verify_google_token(credential: str) -> dict:
    """Google JWT を検証してペイロードを返す。不正なら abort(401)。"""
    try:
        info = id_token.verify_oauth2_token(
            credential, google_requests.Request(), GOOGLE_CLIENT_ID
        )
    except ValueError:
        abort(401, "Invalid token")

    # ドメイン検証（サーバー側で必ず行う）
    if not info["email"].endswith(f"@{SCHOOL_DOMAIN}"):
        abort(403, "School account required")
    return info

@app.route("/api/auth/login", methods=["POST"])
def login():
    credential = request.json.get("credential")
    info = verify_google_token(credential)
    # ユーザーをDBに upsert
    upsert_user(info["email"], info["name"], info.get("picture", ""))
    return jsonify({"name": info["name"], "email": info["email"]})

@app.route("/api/magazines", methods=["GET"])
def get_magazines():
    with get_db() as db:
        rows = db.execute(
            "SELECT * FROM magazines ORDER BY published DESC LIMIT 50"
        ).fetchall()
    return jsonify([dict(r) for r in rows])

@app.route("/api/magazines", methods=["POST"])
def create_magazine():
    credential = request.headers.get("X-Google-Credential")
    info = verify_google_token(credential)
    data = request.json()
    # 必須フィールド検証
    if not data.get("title"):
        abort(400, "title is required")
    return jsonify(save_magazine(info["email"], data)), 201

schema.sql SQL 
CREATE TABLE users (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  email      TEXT UNIQUE NOT NULL,
  name       TEXT NOT NULL,
  picture    TEXT DEFAULT '',
  coins      INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME DEFAULT (datetime('now'))
);

CREATE TABLE magazines (
  id            TEXT PRIMARY KEY,
  author_email  TEXT NOT NULL REFERENCES users(email),
  title         TEXT NOT NULL,
  subtitle      TEXT DEFAULT '',
  cover_url     TEXT DEFAULT '',
  sections_json TEXT NOT NULL DEFAULT '[]',
  published     DATETIME DEFAULT (datetime('now'))
);

CREATE TABLE coin_logs (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_email TEXT NOT NULL REFERENCES users(email),
  label      TEXT NOT NULL,
  amount     INTEGER NOT NULL,  -- 負の値 = 支出
  created_at DATETIME DEFAULT (datetime('now'))
);

-- 知恵袋
CREATE TABLE qa_questions (
  id         TEXT PRIMARY KEY,
  author     TEXT NOT NULL REFERENCES users(email),
  title      TEXT NOT NULL,
  body       TEXT NOT NULL,
  category   TEXT NOT NULL DEFAULT 'general',
  bounty     INTEGER NOT NULL DEFAULT 0,
  solved     BOOLEAN NOT NULL DEFAULT 0,
  created_at DATETIME DEFAULT (datetime('now'))
);
CREATE TABLE qa_answers (
  id          TEXT PRIMARY KEY,
  question_id TEXT NOT NULL REFERENCES qa_questions(id),
  author      TEXT NOT NULL REFERENCES users(email),
  body        TEXT NOT NULL,
  thanks      INTEGER NOT NULL DEFAULT 0,
  best        BOOLEAN NOT NULL DEFAULT 0,
  created_at  DATETIME DEFAULT (datetime('now'))
);

-- フリマ
CREATE TABLE flea_items (
  id         TEXT PRIMARY KEY,
  seller     TEXT NOT NULL REFERENCES users(email),
  name       TEXT NOT NULL,
  category   TEXT NOT NULL,
  description TEXT DEFAULT '',
  image_url  TEXT DEFAULT '',
  price      INTEGER NOT NULL,
  area       TEXT NOT NULL,
  sold       BOOLEAN NOT NULL DEFAULT 0,
  created_at DATETIME DEFAULT (datetime('now'))
);

-- カレンダー
CREATE TABLE calendar_events (
  id         TEXT PRIMARY KEY,
  user_email TEXT NOT NULL REFERENCES users(email),
  title      TEXT NOT NULL,
  date       TEXT NOT NULL,  -- "YYYY-MM-DD"
  type       TEXT NOT NULL DEFAULT 'personal',
  note       TEXT DEFAULT '',
  created_at DATETIME DEFAULT (datetime('now'))
);

-- コイン残高を安全に更新するトランザクション例
BEGIN TRANSACTION;
  UPDATE users SET coins = coins - 500
    WHERE email = 'student@n-high.jp' AND coins >= 500;
  INSERT INTO coin_logs (user_email, label, amount)
    VALUES ('student@n-high.jp', '記事をトップ固定', -500);
COMMIT;

Google 認証 — 詳細仕様

必要な Google Cloud 設定

  1. Google Cloud Console (console.cloud.google.com) でプロジェクト作成
  2. 「APIとサービス」→「認証情報」→「OAuth 2.0 クライアントID」を作成
  3. 「承認済みの JavaScript 生成元」に https://your-school-domain.jp を追加
  4. 「承認済みのリダイレクト URI」を設定（SPAの場合は不要）
  5. 取得した クライアントID を GOOGLE_CLIENT_ID に設定
セキュリティ注意
JWT のデコードはクライアント側でも行っていますが、署名の検証はサーバー側でのみ実施してください。クライアント側検証は表示用途のみです。
設定値説明例
GOOGLE_CLIENT_IDOAuth クライアントID123...apps.googleusercontent.com
SCHOOL_DOMAIN許可するメールドメインn-high.jp
hd パラメータGoogle側のドメイン制限SCHOOL_DOMAIN と同一値を設定

XSS 対策

全てのユーザー入力は esc() 関数で HTML エスケープしてから DOM に挿入。

escape.js JavaScript 
function esc(s) {
  return String(s).replace(
    /[&<>"]/g,
    function(c) {
      return {
        "&": "&amp;", "<": "&lt;",
        ">": "&gt;", '"': "&quot;"
      }[c];
    }
  );
}
// innerHTML への代入はすべて esc() でラップすること
